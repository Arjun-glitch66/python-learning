Decimal    Binary
  1        0001
  2        0010
  3        0011
  4        0100
  5        0101
  6        0110
  7        0111

So when we write:
a = 5b = 3


internally:
5 = 0101
3 = 0011

Bitwise operators operate bit by bit.
2. & AND
Rule:
1 & 1 = 1
Everything else = 0

Take:
5 & 3

Binary:
  0101   ← 5
& 0011   ← 3
------
  0001

Look at each column:
0 & 0 = 0
1 & 0 = 0
0 & 1 = 0
1 & 1 = 1

So:
0001 = 1

Therefore:
print(5 & 3)


gives:
1

Think of AND as:
Both must be 1.

3. | OR
Rule:
0 | 0 = 0
Everything else = 1

Again:
5 | 3

  0101
| 0011
------
  0111

Column by column:
0 | 0 = 0
1 | 0 = 1
0 | 1 = 1
1 | 1 = 1

0111 is:
4 + 2 + 1 = 7

Therefore:
print(5 | 3)


7

Think of OR as:
At least one must be 1.

4. ^ XOR
This one is slightly different.
Rule:
Same → 0
Different → 1

So:
5 ^ 3

  0101
^ 0011
------
  0110

Why?
0 ^ 0 = 0   same
1 ^ 0 = 1   different
0 ^ 1 = 1   different
1 ^ 1 = 0   same

0110 =
4 + 2 = 6

Therefore:
print(5 ^ 3)


gives:
6

Think of XOR as:
Different = 1, same = 0

5. ~ NOT
This one flips the bits.
Conceptually:
0 → 1
1 → 0

For example, ignoring signed-number representation for a moment:
0101

becomes:
1010

In Python, however:
print(~5)


gives:
-6

2. Left shift by 2
Now:
5 << 2


Start:
0101

Move left twice:
0101
  ↓
1010
  ↓
10100

10100 = 20

So:
print(5 << 2)


Output:
20
The easy shortcut
For positive numbers:
x << 1  → x × 2
x << 2  → x × 4
x << 3  → x × 8

4. Right shift by 2
5 >> 2


Start:
0101

Move right once:
0010

Move right again:
0001

So:
0001 = 1

Therefore:
5 >> 2


gives:
1

🚨 Another easy shortcut
For positive numbers:
x >> 1  → x ÷ 2
x >> 2  → x ÷ 4
x >> 3  → x ÷ 8
